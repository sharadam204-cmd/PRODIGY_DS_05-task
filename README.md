PRODIGY_DS_05


This project focuses on analyzing road accident data to identify patterns and factors contributing to traffic accidents. Various data visualization techniques were used to study accident severity, weather conditions, road surface conditions, and time-based accident trends.

Features:

Accident severity analysis

Weather condition analysis

Road surface condition analysis

Time-based accident trend visualization

Data preprocessing and exploratory data analysis (EDA)






Technologies Used:

Python

Pandas

Matplotlib

Google Colab


Dataset: Road Accident Dataset from Kaggle.

Outcome: Successfully analyzed traffic accident patterns and visualized important insights related to accident severity, weather conditions, and accident-prone situations to better understand road safety trends.
